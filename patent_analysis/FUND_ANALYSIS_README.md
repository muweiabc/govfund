# 政府引导基金分析工具

## 功能概述

本工具用于分析政府引导基金的时间和空间分布特征，生成可视化图表和统计报告。

## 主要功能

### 1. 基金成立时间分析
- 分析基金成立年份的分布情况
- 生成柱状图显示各年份基金数量
- 识别基金成立的高峰期和低谷期

### 2. 基金地理分布分析
- 分析基金在不同省份的分布情况
- 生成饼图和柱状图显示省份分布
- 识别基金集中的主要省份

## 生成的文件

### 图片文件
1. **`fund_distribution.png`** - 综合分布图（年份柱状图 + 省份饼图）
2. **`fund_year_distribution.png`** - 详细的年份分布柱状图
3. **`fund_province_distribution.png`** - 详细的省份分布柱状图（前20名）

### 数据统计
- 总基金数量
- 成立年份范围
- 涉及省份数量
- 详细的年份分布统计
- 详细的省份分布统计

## 使用方法

```bash
# 运行分析
python patent_analysis/analyze_fund.py
```

## 数据来源

- **输入文件**: `govfund_filtered.xlsx`
- **主要字段**:
  - `成立时间`: 基金成立日期
  - `注册地区`: 基金注册地区（格式：中国|省份|城市|区县）

## 技术特点

### 数据处理
- 自动处理日期格式转换
- 智能提取省份信息（从层级地区数据中）
- 处理缺失值和异常数据

### 可视化设计
- 支持中文显示
- 高分辨率图片输出（300 DPI）
- 多种图表类型（柱状图、饼图）
- 数值标签和网格线
- 专业的配色方案

### 统计分析
- 描述性统计
- 排序和分组分析
- 前N名统计
- 汇总信息输出
